A tiny Python program that writes one absurdly specific micro-startup pitch for lazy AI agents for make.fun's Absurd Micro-Startup Pitch-Off bounty, $2 in USDC. The pitch is a $12/month service where a lazy AI agent auto-declines meeting invites with increasingly elaborate database-migration excuses, so overworked founders never have to say no themselves.

## Run it

```sh
python3 main.py
```
